# ResQPlate frontend

The complete and maintained project documentation is in the [repository README](../README.md).

## Quick start

This directory contains the Vite application. From this directory:

```bash
npm ci
```

Copy `.env.example` to `.env`, configure Appwrite, and then run:

```bash
npm run dev
```

Before submitting changes, run:

```bash
npm run lint
npm run build
```

See the repository README for the exact environment variables, Appwrite collection schema, permissions, routes, deployment instructions, and troubleshooting guidance.
